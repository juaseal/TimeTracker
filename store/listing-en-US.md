## Short description

## Description
TaskUp helps you track time spent on projects, epics, and activities from a fast, private desktop application. Review daily records, check weekly summaries, mark favorite tasks, and copy SAP-ready time entries using a configurable rounding policy.

Your data stays on your device. You can export your complete history to CSV and create local backups at any time.

## Features
- Activity timer with compact widget mode
- Editable daily history
- Weekly summaries by project and epic
- SAP-ready export and clipboard formats
- Configurable time-entry rounding
- Custom work schedules and calendar periods
- Favorite and recent tasks
- Reports by project, activity, and comment
- CSV export and local backups
- Light and dark themes with accessibility options
